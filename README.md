step-1 : install node.js from its official website - https://nodejs.org/en/download -> check the node version (node -v) and npm version (npm -v)
Step-2 : clone this project - git clone https://github.com/sumantind/nodejs-proj1.git
step-3 : run the command in terminal : npm install
step-4 : run the particular file by this command -> node file-name(like abc.js) {You will see the output in terminal}
step-5 : install nodemon -> npm install nodemon -> then you can run the file -> nodemon file-name {You can see the output in browser}
